# Foundry private alpha

The Foundry private alpha is an invitation-only Windows x64 evaluation channel.
It is intended to prove that creators can install the product and complete the
build, test, package, deployment, repair, update, recovery, and reporting
journeys without a developer beside them.

Start with [tester onboarding](tester-onboarding.md), then record the result in
the [acceptance checklist](acceptance-checklist.md). The approved host versions
are in the [published compatibility matrix](../compatibility/private-alpha-matrix.md).

Private alpha packages are shared through an access-controlled location. The
manifest SHA-256 is sent separately in the tester invitation. SHA-256 proves
that the received files match that invitation; it does not by itself identify
the publisher. Do not install a bundle received from an uninvited third party.

Foundry has no telemetry or automatic issue upload. See the
[privacy statement](../privacy-and-offline.md), [update strategy](update-strategy.md),
[crash-recovery review](crash-recovery.md), and [issue workflow](issue-reporting.md).
