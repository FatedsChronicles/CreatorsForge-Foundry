# Creators Forge Foundry 1.0.0

Creators Forge Foundry 1.0.0 is the first stable release of the local-first
Windows development environment for creating Streamer.bot extensions and
native OBS Studio plugins.

## Highlights

- Create, edit, validate, build, test, package, publish, deploy, repair, roll
  back, and uninstall Streamer.bot and OBS projects from one desktop workspace.
- Use Roslyn-powered C# tooling, pinned libobs native-code assistance, verified
  snippets, designers, Solution Explorer operations, an integrated PowerShell
  terminal, and crash-isolated executable previews.
- Produce deterministic provider packages, CPHInline bridges, Streamer.bot
  imports, native OBS modules, publishing metadata, dependency inventories, and
  reproducibility reports.
- Install and update Foundry with native Windows executables while preserving
  user projects, settings, and recovery data.
- Choose Stable or Prerelease update channels backed by verified GitHub Release
  manifests and SHA-256 validation.

## Verified host compatibility

Foundry 1.0.0 is verified against these exact hosts:

- Streamer.bot 1.0.4 stable;
- Streamer.bot 1.0.5-alpha.34;
- Streamer.bot 1.0.5-beta.1;
- Streamer.bot 1.0.5-beta.6;
- Streamer.bot 1.0.7 stable;
- OBS Studio 32.1.2 Windows x64; and
- OBS Studio 32.2.1 Windows x64.

The OBS `32.x-windows-x64` profile identifies the supported project family. It
does not claim compatibility with every OBS 32.x release.

## Installation and updates

Download `CreatorsForge-Foundry-1.0.0-Setup.exe` for a new installation. The
default location is `C:\Program Files\Creators Forge\Foundry`, and setup also
supports a user-selected location. Existing supported installations can use
Foundry's verified updater or run `CreatorsForge-Foundry-1.0.0-Update.exe`.

Foundry's uninstaller removes installer-owned application files and shortcuts
while preserving user-owned projects, settings, recovery snapshots, and host
configuration.

## Important release notes

- Foundry is local-first and includes no telemetry. Network access occurs only
  for an explicitly requested update check, SDK download, or external link.
- Streamer.bot mock tests and the isolated OBS lifecycle harness supplement,
  but do not replace, real-host verification.
- Native OBS development requires CMake, Visual Studio C++ x64 tools, a Windows
  10/11 SDK, and Foundry's pinned OBS SDK. The guided toolchain window discovers
  and validates these dependencies without changing the machine PATH.
- Stable publisher signing requires an approved Authenticode certificate. If
  the release owner explicitly approves an unsigned 1.0.0 build, Windows may
  display an unknown-publisher warning during installation.
