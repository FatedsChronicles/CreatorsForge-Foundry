# Creator Goal Overlay

Representative Phase 22C static-web preview project. The isolated adapter adds
safe browser-like chrome and semantic element styling while blocking scripts,
external navigation, and browser-engine execution.

Open the project and press **Ctrl+Shift+P**. Saving `ui/index.html` demonstrates
the debounced refresh workflow. `styles.css` and `overlay.js` are representative
project assets; Phase 22C does not execute them.
